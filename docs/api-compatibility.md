# API compatibility

What the Nuu addons ask of the WoW: Forever client (`_classic_beta_`, `## Interface: 16001`), and what was seen when
it was tried. Record every result with the build and the date; never guess a client version. OpenRoad keeps its own
record (`../AddOns/OpenRoad/docs/api-compatibility.md`); rows there are evidence, not results for Nuu.

Nothing below has been tried in the client yet. `/nuukit ui` opens the kit's gallery, which shows every widget; the
"to verify" column says what to look for there.

| Feature | APIs | Result | Fallback | Build | Date |
| --- | --- | --- | --- | --- | --- |
| Glyphs (chevrons, close, menu, check, grip, lens) | `Frame:CreateLine`, `Line:SetStartPoint` / `SetEndPoint` / `SetThickness`, `SetColorTexture` on a line | unverified - to verify: the gallery's Glyphs row shows clean marks in the accent on hover; a section's chevron flips when folded | an ASCII character (`x`, `>`, `v`, `=`, `+`) in its place | - | - |
| Flat plates and text | `Texture:SetColorTexture`, `FontString:SetFont(file, size, "")`, `SetShadowColor` / `SetShadowOffset`, `GameFontNormal:GetFont()`, `NumberFontNormal:GetFont()` | unverified - to verify: every theme in the Look tab repaints all open windows at once; Large text size grows every label and the layout makes room | `Fonts\FRIZQT__.TTF` and `Fonts\ARIALN.TTF` when the font objects are missing | - | - |
| Art theme textures | `Texture:SetTexture(path)` on 32-bit uncompressed TGA from `Tools/Textures.py`, `SetTexCoord` for the 9-slice, `SetTexture(path, "REPEAT", "REPEAT")` with `SetHorizTile` / `SetVertTile` | unverified - to verify: Horde and Alliance show the leather / slate background tiled without seams, the frame with square corner caps that do not stretch, the textured header band and button plates | a texture that does not load is drawn flat from the theme's colours, piece by piece | - | - |
| Attention animations | `CreateAnimationGroup`, `Alpha` (`SetFromAlpha` / `SetToAlpha`, else `SetChange`), `Translation` (`SetOffset`), `SetLooping`, `Frame:SetClipsChildren`; pulse and trail by `OnUpdate` with `SetPoint`, `SetSize` and `SetAlpha` | unverified - to verify: the gallery's attention buttons breathe, pulse a crisp ring outward that fades, sweep a glint across (clipped to the button), blink twice then stop, and march dashes clockwise round the edge with no gap at the corners; Less motion stills them to a wash, the trail to still dashes | a still wash | - | - |
| Windows | `GetCursorPosition` with `GetEffectiveScale` and `IsMouseButtonDown` for moving and sizing by hand (not `StartMoving` / `StartSizing`), `SetResizable`, `SetResizeBounds` (else `SetMinResize` / `SetMaxResize`), `SetClampedToScreen`, `SetToplevel`, named frame in `UISpecialFrames`, `SetClipsChildren` on the body | unverified - to verify: the gallery drags by its band, resizes from the grip within its bounds (made small, nothing shows past its edge), and in both the point grabbed stays under the cursor however fast it moves, even when let go off the window; every 1 pixel edge draws 1 pixel wide at any UI scale, and pressing Reset guide on Controls changes no other border, closes on Escape, and a panel collapses to one line and back | no resize bounds on a client without either call | - | - |
| Pixel grid | `GetPhysicalScreenSize` with `GetEffectiveScale` (a pixel is the effective scale times the physical height over 768, as Blizzard's `PixelUtil` has it) to snap places, sizes and scroll offsets to whole screen pixels; hairlines one pixel and strokes whole pixels by `SetHeight` / `SetWidth`; the `UI_SCALE_CHANGED` and `DISPLAY_SIZE_CHANGED` events (registered through pcall) to redo it all | unverified - to verify: at two or three UI scales (Options, "Use UI scale"), every plate edge and rule in the gallery is 1 pixel wide and even, the tab underline and slider track are even; change the UI scale with the gallery open and the edges stay 1 pixel; pressing Reset guide on Controls changes no other border, nor does moving the gallery slowly across the screen | without the events, edges keep their old thickness until `/reload` after a scale change; without `GetPhysicalScreenSize`, the grid is the effective scale alone and edges can still shift by a pixel | - | - |
| Fields | `EditBox` with `SetTextInsets`, `HighlightText`, `SetMultiLine`, `OnTabPressed`, `OnArrowPressed`, `OnCursorChanged`, `SetMaxLetters`, `SetNumeric`, `GetCurrentKeyBoardFocus`, `EditBox:SetText` with `|cff...|r` colour codes for a money field at rest | unverified - to verify: a money field shows its coin letters in gold, silver and copper, turns plain when clicked into, and back when left without counting as a change; Tab moves through a window's fields in order; Enter commits, Escape restores; a text area grows and scrolls to keep the cursor in view; arrows in a search field move the list selection | - | - | - |
| Menus | one frame at `FULLSCREEN_DIALOG` with a full-screen click catcher, `GetCursorPosition` for a right-click menu | unverified - to verify: a select opens under its left edge; a click outside closes it; a submenu opens on hover; a check entry toggles without closing; the search box filters | - | - | - |
| Slider | `CreateFrame("Slider")`, `SetThumbTexture("Interface\\Buttons\\WHITE8x8")`, `SetObeyStepOnDrag`, `OnMouseWheel` | unverified - to verify: the thumb drags in steps, the wheel moves it, the readout follows | steps enforced in `OnValueChanged` | - | - |
| Slots | `C_Item.GetItemIconByID` / `GetItemIcon`, `C_Item.GetItemQualityByID` / `GetItemInfo`, `C_Item.GetItemQualityColor` / `ITEM_QUALITY_COLORS`, `C_Container.GetItemCooldown`, `CreateFrame("Cooldown", ..., "CooldownFrameTemplate")`, `SecureActionButtonTemplate` attributes out of combat, `Interface\TargetingFrame\UI-RaidTargetingIcon_1` to `_8` for a slot's raid marker | unverified - to verify: the gallery's item strip shows icons with quality edges, key hints and counts (on a shaded strip), a gold "!" on the first slot and a skull on the fourth; the Hearthstone shows its cooldown sweep; the missing candle is dimmed with a red edge | no icon, border edge, no cooldown sweep | - | - |
| Tooltips | `GameTooltip:SetOwner`, `SetText`, `AddLine`, `SetItemByID`, `SetSpellByID`, `SetHyperlink`, `GameTooltipTemplate` for the chained tooltip | unverified - to verify: a disabled button's tooltip gives its reason in red; a slot shows the game's item tooltip | - | - | - |
| Keyboard control (opt-in) | `EnableKeyboard`, `OnKeyDown`, `SetPropagateKeyboardInput` | unverified - to verify: In play > Full keyboard lets Tab reach buttons with the focus ring, Space presses, arrows move a slider or tab, and every other key still reaches the game; check in combat too | fields-only Tab order | - | - |
